2020年8月のポートフォリオ

現在の構成

お盆連休最後の日曜日は、毎年資産運用を見直すのが慣例になっている。現在のポートフォリオを列挙する。

1. 仮想通貨の自動売買

仮想通貨を売買するうえで最大のメリットは株と違い、APIが利用できるので自動売買プログラムを開発できること。これが楽しくてここ数年どっぷりはまっている。
全然稼げていないがいつか利益が出ることを信じて・・・

Bitbank

仮想通貨取引所としてはメインで利用している。自動売買プログラムを開発中。UIが綺麗で、APIが使いやすい。
現物の板取引が充実しており、取り扱い銘柄が豊富。また、最小購入単位が全銘柄0.0001とxrpなら1円以下から購入できるので、自動売買の戦略が広がる。

Bitflyer

最近使っていない。btcfxで空売りしたいときに利用している。いつか自動売買プログラムを開発したい。

CoinCheck

この会社独自のサービスがいろいろとあり、試しに小額預けている。貸し仮想通貨というものがあり、様々な銘柄を小額から貸し出すことができるため、そこに少し預けている。botをつくる予定はない。

2. 国内株式

主に自分の興味のある業界の銘柄を購入している。選定に関してはかなり主観的で、その会社のコンテンツが流行りそうかどうかで選んでいる。例えばbitbankを運営している会社の親会社…とか、好きなアニメの制作会社…とか。どちらかというと売買差益重視。
最近は決算情報も見るようにして、判断材料の一部にしている。
証券会社はauカブコム証券。

3. 投資信託

不動産系とアフリカ系の投資信託に小額預けている。

不動産系は毎月分配金を入手できるので持っていて楽しい。ワールドリートオープンという昔からある投資ファンドに投資していたが、あまり利率が高くないようなので、J-REIT系の投資ファンドに移行中。

アフリカ系はFACTFULNESSという本を読んだ影響。世界は総じて豊かになってきており、アフリカも例外ではない。大きな経済発展が見込める最後の大陸なのでということで、アフリカ企業に投資している投資ファンドを探したらあった。

あと、WealthNaviにも小額預けている。あまり評判が良くないのでお試しで利用中。

4. FX

OANDA Japan

APIが利用できる取引所はOANDAくらいしかない。今は仮想通貨の自動売買に集中していてFXは利用していないが、為替FXにも使えるロジックを開発しているので、いつか挑戦したい。

今後利用したいサービス

外国株式

SBI証券とマネックス証券でアメリカの株が買えるらしいので、SBI証券の口座開設中。

不動産クラウドファンディング

OhYaという不動産投資紹介サイトで興味を持った。不動産投資信託とは異なり、自身が物件のオーナーになることができる。ところがコロナのせいか案件が少ない。

株式クラウドファンディング

このブログ記事を読んで興味を持った。

株式投資型クラウドファンディングで未公開株を手に入れる方法

エンジェル投資税制？というものがあり、控除されるらしい。
自由に売買できないので、配当金目当てで投資するのだが敷居が少し高いかもしれない。

DeFi

twitterのタイムラインで話題になっているが調べていないのでよくわからない（草コイン？インデックス？）幅を広げ過ぎな感じがあるので、時間があれば。

EDINET

決算書調べるの楽しい

noteの妄想する決算さんに影響を受けて
決算書を読むのが少し楽しくなってきた。
各企業のHPでIR情報を覗いてしていたが、効率悪いので
何かAPIのようなもので一括で取得できないか調べてみた。

効率的にデータ収集したい

どうやら金融庁が日本の企業の有価証券報告書をDBで管理しているらしい。
EDINETというものがあるらしい。
誰でもAPIを利用してデータを閲覧できるらしい。
こんな素晴らしいシステムに気がつかないなんて情弱なんじゃないかと気が滅入ったが、
気を取り直して、このAPIを利用してみようと思う。

EDINET API

EDINET APIというものがあった。
仕様書を読んでみると、どうやら諸々の報告書をダウンロードするためのAPIで、
私が欲しい企業の売上とか資産とかの情報は、pdfもしくはxmlのようなファイルに記載してあるっぽい。
日本中の企業の情報をデータベース化したいけど、なかなか工数がかかりそうだ。

2020-07-05

株式会社について調べた

決算について

決算を読めるようになりたいと思い、いろいろな企業のIR情報を調べてみた。
従業員数、資産、負債、売上純利益、営業利益、純利益を一覧にしてみた。
自分の会社についても調べてみた。
東証一部企業よりも規模は劣るが、営業利益や純利益はそこそこある。
資産と負債が異常に少ないのはなぜだろう・・・

株式会社について

株式会社の仕組みについて調べてみた
株式会社は株主が所有権、経営権的な権利を持つようだ。
そして、経営する株主を社員と呼ぶそう。
一般的な社員の意味合いとは異なる。一般的な社員はいわゆる従業員と呼べばいいのか。

投資家が多くの株式を持っていると、経営権がもっていかれてしまうので、
経営者や従業員持株会のようにある程度、株を保有していないといけない？

大株主欄に、信託銀行の名が目に付く、
信託銀行は、機関投資家から株式の売買を委託されているらしい。
機関投資家は、日銀等も含み、匿名性を保つために信託銀行経由で株を購入しているらしい。

企業はどのタイミングで、株式から資金を得るのだろうか？
日銀は毎年のように株を購入しているらしい。その金はどこからでているのか？

node.jsプログラムをバックグラウンドで実行する

通常の実行方法だと（node xxx）
コンソールを終了すると（ubuntuからログアウトすると）nodejsスクリプトが終了してしまう。

バックグラウンドでプログラムを実行したいときは、nohupコマンドを使う。
sudo nohup node main &
でバックグラウンドでnode.jsスクリプトを実行する
プロセスが実行しているかどうかは
ps -fu root
で確認する
プロセスを終了したいときは
kill プロセスID
で終了する
※二重起動して、API使用制限オーバーしてBANされたりしたらやだなぁ
API使用状況を確認できる機能を実装したい

ubuntuの時間を日本時間にする

ubuntuの場合は、下記のようにリンクを張り替えるだけでいけた。
ln -sf /usr/share/zoneinfo/Asia/Tokyo /etc/localtime
